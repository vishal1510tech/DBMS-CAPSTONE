# Intelligent Library and Digital Resource Management System (ILDRMS)
### Capstone Project: DBMS Problem Statement #4 (100 Marks Evaluation Framework)

An enterprise-grade, academically comprehensive Relational Database Management System (RDBMS) project developed for university capstone submissions. It models and implements physical book circulation, digital asset subscriptions (e-books, journals, audio licenses), member privileges, waitlist reservation queues, automated penalty assessments, and advanced SQL analytics.

## 4. Database Schema Highlights

- **12 Normalized Tables in BCNF**:
  - `publishers`, `authors`, `categories`, `resources`, `resource_authors` (M:N), `book_copies` (1:N), `digital_assets` (1:1), `members`, `circulation_transactions`, `reservations`, `fines_and_penalties`, `fine_payments`.
- **Relational Integrity**:
  - Domain checks (e.g. `available_copies <= total_copies`, positive pricing, date chronology).
  - Explicit cascade actions (`ON DELETE CASCADE`, `ON DELETE RESTRICT`, `ON DELETE SET NULL`).
- **Advanced Query Techniques**:
  - Recursive Common Table Expression (CTE) dynamically generates breadcrumb trails for nested subject taxonomy trees.
  - Window functions segment patron reading habits into quartiles (`NTILE(4)`) and calculate borrowing cadences using `LAG()` and `LEAD()`.
  - Composite indexes optimize batch overdue jobs and shelf barcode seeks.
