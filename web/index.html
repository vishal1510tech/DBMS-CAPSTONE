Formal Normalization Journey (1NF to BCNF)

Mathematical progression eliminating data redundancy and modification anomalies.

1NF: Atomicity Passed

Eliminates repeating groups. All attribute values are atomic indivisible units.

• Split MemberName into first_name, last_name
• Authors list split into resource_authors bridge
• Single barcode per book copy
2NF: No Partial FDs Passed

Eliminates partial dependencies on composite keys. Non-key attributes depend on entire candidate key.

• In (resource_id, author_id), removed title & author bio
• Separated book_copies from master catalog
3NF: No Transitive FDs Passed

Eliminates transitive dependencies (X → Y and Y → Z). Non-key depends only on primary key.

• Extracted publishers (resource → publisher_id → name)
• Extracted categories (resource → category_id → name)
• Extracted fines from circulation
BCNF: Superkey Determinants Achieved

Strict Boyce-Codd Form: in every non-trivial FD (X → Y), determinant X MUST be a superkey.

• book_copies: both copy_id & barcode are superkeys
• resources: both resource_id & isbn are superkeys
• All 12 tables 100% compliant
